# Fluxos

Um documento por fluxo. Cada um tem a mesma estrutura:

1. **Telas** — capturas e rota.
2. **O que o Figma mostra** — conteúdo obrigatório.
3. **API** — endpoints usados.
4. **Estados** — carregando, vazio, erro e casos especiais (incluindo os não desenhados).
5. **Subitens** — **a definir com o usuário.** A lista que aparece em cada arquivo é só um rascunho do Opus para a conversa; nada é implementado a partir dela até o usuário validar.
